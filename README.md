# IskuXidh - Shaqo iyo Shaqaale

IskuXidh waa madal isku xirta shaqo-bixiyeyaasha iyo xirfadlayaasha Soomaaliyeed.

## Features
- **Raadi Shaqo:** Ka raadi shaqooyin dalka oo dhan.
- **Shaqo Soo Geli:** Loo-shaqeeyayaasha waxay soo dhigi karaan fursado shaqo.
- **Chat:** Wada-hadal toos ah oo u dhexeeya qofka shaqada raadinaya iyo loo-shaqeeyaha.
- **Lacag-bixin:** Nidaamka diiwaan-gelinta (Registration Fee) ee mobilka.
- **Luuqad:** Waxaa lagu heli karaa Af-Soomaali iyo English.

## Technology Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript.
- **Backend:** Supabase (Auth, Database, Real-time).
- **Icons:** Lucide Icons.

## Sida loo isticmaalo
Kaliya gal bogga `auth.html` si aad isku diiwaan-geliso!
